# China Outbound Service DPA Bilingual

Codex skill for drafting, reviewing, redlining, and formatting bilingual Chinese-English Data Processing Agreement annexes for Chinese outbound service companies serving overseas enterprise customers.

## What It Covers

- GDPR, UK GDPR, CCPA/CPRA, and PIPL framework-level drafting
- Controller / entrusted processor scenarios for outbound Chinese service providers
- Affiliate and third-party sub-processor positions
- Cross-border remote access and transfer drafting notes
- Technical and organizational measures
- Word output guidance for `.docx` deliverables

## Contents

- `SKILL.md` - main skill instructions and metadata
- `references/default-scenario.md` - default factual assumptions
- `references/drafting-framework.md` - clause framework and bilingual drafting rules
- `references/word-output.md` - Word document formatting guidance
- `agents/openai.yaml` - agent configuration
- `LICENSE.txt` and `NOTICE.txt` - license and attribution notices
